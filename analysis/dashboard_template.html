    // 15 DATA

    Where the questions come from

    Every item was written by hand by Giorgi Kobaidze, a native Georgian speaker: no machine-generated or translated text. The full sets were then trimmed to the items that actually separate models, because every question costs model credits. Easy items were removed using a thinking model (Gemini 3 Flash) as a probe; every item it got wrong was kept.

    The full, untrimmed sets are kept in the repository's archive/ folder for later testing.

    // 16 SCORING

    How each task is scored

    Numbers
    Write a number in Georgian words, or a Georgian number in digits, as cardinal and as ordinal. One call per question, exact match after Unicode normalization. Dash variants count as the same character.
    Verbs
    Read who does what to whom from a verb form, choose the right preverb (multiple choice, answered with a letter), or build a verb form for given persons and tense (exact match).
    Translation
    Translate a Georgian paragraph into English. A fixed judge model (Gemini 3 Flash, without thinking) compares the meaning with the author's reference translation on a 5-level scale; wording and style do not count, and he/she/they choices are never penalized where Georgian has no gender.
    Cloze
    Fill 25 numbered gaps in an article with the right grammatical form of words from a list that also contains distractors. Every gap counts on its own: right word, right form, right place.
    Correction
    Fix planted grammar, spelling and punctuation errors in a paragraph. Partial credit, word by word: every fixed error counts, and every correct word the model changes counts against it, exactly like a missed error.

    Task scores run from 0 to 1. A model's average is the plain mean of its 5 task scores, each task counting equally.

    // 17 CONDITIONS

    Same conditions for every model

    • No thinking. Every model answers directly, without hidden reasoning. Default settings would have mixed models that think with models that don't, which is not a fair comparison.
    • One exception, clearly marked. GPT-6 Astra cannot switch thinking off; its minimum is "low". So the newest pair, Claude Opus 5 and GPT-6 Astra, both think at "low". They are marked LOW everywhere.
    • Pairs of comparable models. Each level pairs an Anthropic and an OpenAI model of the same class: light, decent, top, newest.
    • Same prompts, same code. All models run the same task version on Kaggle Benchmarks, with English instructions and Georgian content.
    • An output limit of 32,000 tokens per answer, far above any answer in the runs. It only exists because Kaggle reserves the worst-case cost of every call before sending it.
    • One run per model. Re-runs of the same model differed by about ±0.03 per task.
    // 18 BUDGET

    Built on a free quota

    Kaggle provides model credits of $10 per day. Before each call, Kaggle reserves the worst possible cost (the model's maximum answer length × its price) and refuses the call if that does not fit, even when the real answer costs a fraction of a cent. That shaped the benchmark: trimmed item sets, two parallel calls instead of four, the output limit, and no thinking. The Cost & tokens tab shows where every dollar went.

    // 19 LIMITS

    Read the results with this in mind

    • The sets are hard by design. Numbers and verbs keep mostly items a strong model got wrong, so absolute scores are low. The ranking between models is the meaningful part.
    • Small sets. Some tasks have only 12 to 17 items, so differences of a few points are not significant.
    • Some answers are debatable. In a few items every model agrees with each other against the expected answer; these are shown in the Tasks tab.
    • The token gap includes format overhead. Input tokens cover the prompt plus each vendor's answer-format instructions, so part of the gap is not Georgian text itself.
    • The judge is a model. Translation scores depend on Gemini 3 Flash's judgment of meaning.
