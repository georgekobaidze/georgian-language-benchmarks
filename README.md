# Georgian Language Benchmarks (GLB) for Kaggle

How well do AI models really know Georgian?

Georgian is a low-resource language for AI, and an unusual one: it has its own
script, counts in base 20, and its verbs agree with both subject and object.
This benchmark tests models on those features, with gold answers written and
checked by a native speaker. It is built for the
[DEV x Kaggle Benchmarking Challenge](https://dev.to/challenges/kaggle-2026-09-23)
and runs on [Kaggle Benchmarks](https://www.kaggle.com/benchmarks).

## What it tests

| Dimension              | Example                                                      | Scoring                       |
| ---------------------- | ------------------------------------------------------------ | ----------------------------- |
| Script and orthography | Count letters, sort alphabetically, transliterate            | Exact match                   |
| Numbers                | 99 is ოთხმოცდაცხრამეტი ("four twenties and nineteen")        | Exact match                   |
| Verb morphology        | Who did what to whom, from a single verb form                | Exact match / multiple choice |
| Grammar judgment       | Find the case or agreement error                             | Multiple choice               |
| Real-world input       | Chat Georgian typed in Latin letters, wrong keyboard layout  | Character error rate          |
| Reasoning parity       | The same logic problems in English and in Georgian           | Accuracy gap                  |
| Language fidelity      | Asked in Georgian, does the model answer in Georgian?        | Script detection              |
| Cultural knowledge     | Proverbs and their meanings                                  | Multiple choice               |
| Vision (optional)      | Read Georgian text from images, including historical scripts | Character error rate          |

## Repository layout

```
data/          questions and correct answers, one CSV per task (published as a Kaggle dataset)
generators/    scripts that generate data automatically
tasks/         one Kaggle task file per dimension
scripts/       helpers to upload data, push tasks and run them on models
models.txt     the Kaggle model catalog at the time of benchmarking
```

## How it works

1. **Data.** Each task reads one CSV from `data/`. Some CSVs are generated by
   scripts in `generators/`, the rest are written by hand.
2. **Upload data.** `scripts/push_data.sh "what changed"` uploads `data/` as
   the Kaggle dataset `georgekobaidze/georgian-language-benchmark-data`.
3. **Push a task.** `scripts/push_task.sh glb-numbers tasks/numbers.py`
   uploads a task with the dataset attached.
4. **Run it.** `scripts/run.sh glb-numbers dev` runs a task on a tier of
   models: `dev` (2 cheap models), `core` (the 8 models analysed in the
   write-up) or `all` (every model in `models.txt`).
5. **Get results.** `kaggle b t download glb-numbers -o results` downloads
   every model's answers and scores.

Run the scripts from the repository root.

## Setup

Requires Python 3.11+ and a Kaggle account.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
kaggle auth login       # once, to connect the CLI to your Kaggle account
kaggle b auth -y        # writes short-lived model credentials to .env (never commit it)
```
